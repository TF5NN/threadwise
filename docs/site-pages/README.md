# Pages for tf5nn.github.io

Copy the `content` folder into the TF5NN.github.io repository (it merges with what is there).
It adds Threadwise to the Apps page in both languages, each with an instructions page and a history page.
The history page has a note where Gunnar's own story of the spreadsheet goes.
The "Open the app" button opens Threadwise in the language the visitor is reading.
